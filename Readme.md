# Atlas Outdoor Raids

Outdoor raid encounter maps for the World of Warcraft Atlas addon.

Atlas Outdoor Raids is an optional Atlas plugin that provides maps for outdoor
raid encounters. It requires the Atlas core addon and does not run as a
standalone addon.

## Downloads

- [Atlas Outdoor Raids on CurseForge](https://www.curseforge.com/wow/addons/atlas-outdoor-raids)
- [Atlas core addon on CurseForge](https://www.curseforge.com/wow/addons/atlas)

Choose releases compatible with your WoW client. Map coverage and available
information may vary by release.

## Installation

1. Install the Atlas core addon.
2. Install Atlas Outdoor Raids for the same WoW client.
3. Enable both addons in the character selection screen's AddOns list.
4. Open Atlas with `/atlas` and select an outdoor raid encounter map.

For manual installation, extract the addon into the `Interface/AddOns`
directory of the WoW client you use. Preserve the addon folder structure
and avoid an extra wrapper folder.

## About This Plugin

Atlas Outdoor Raids was originally included in Atlas. It is now distributed
as a separate addon so players can choose whether to install its maps.

This plugin supplies map content for the Atlas browser; it does not provide
a separate map interface.

This repository contains the Atlas Outdoor Raids plugin, not the Atlas core.
